# Weekly Funnel Report Implementation Plan (F2 + F3)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `lead-funnel report FILE --week YYYY-Www --out DIR` writes `funnel-<week>.xlsx` with per-agency funnel counts, conversion rates, a chart and an About sheet.

**Architecture:** `metrics.py` (pure: week parsing and funnel counts from F1's `Lead` list) feeds `report.py` (openpyxl workbook), which saves through a shared `files.atomic_write`. `cli.py` adds the `report` subcommand and shares the first three summary lines with `check`.

**Tech Stack:** Python >= 3.12, openpyxl (already installed), pytest, ruff. No new dependencies.

**Spec:** `docs/superpowers/specs/2026-11-10-f2-f3-report-design.md` (approved 2026-11-10)

## Global Constraints

- Work in worktree `.claude/worktrees/f2-f3-report` on `feature/f2-f3-report` (from `origin/main` `d50f456`).
- No new dependencies. No formulas in the workbook. No lead ids, names, emails or phones in the report.
- Report path is always `<out_dir>/funnel-<week>.xlsx`; existing file needs `force`.
- Rates: zero denominator gives `None`, shown as text `n/a`. Counts format `#,##0`, rates `0.0%`.
- Exit codes 0/1/2/3 as in `DESIGN.md`. Comments one sentence, no emojis. Fast checks before each commit: `uv run ruff check .` and `uv run pytest -q`.

## Review Focus

1. **Week 53:** `2026-W53` is valid (2026 has 53 ISO weeks), `2025-W53` is not; `default_week(date(2027, 1, 5))` is `2026-W53` (Task 2, `test_week_53`).
2. **`--out` is an existing file, not a folder:** exit 1 `Error: --out <path> is a file, not a folder.`, not the misleading "already exists" (Task 6, `test_report_out_is_a_file`).
3. **Report open in Excel while replacing (PermissionError at `os.replace`):** exit 1 and no temp file left (Task 1 `test_atomic_write_cleans_up_on_replace_error`, Task 6 `test_report_permission_error`).
4. **Non-ASCII agency names** (`Café Events`, `Ñandú Media`): written exactly, width computed without error (Task 4, `test_non_ascii_agency`).
5. **Every row rejected (no leads at all):** `weekly_funnel([], week)` gives no agency rows and a zero Total; report still written (Task 3 `test_no_leads_at_all`, Task 6 `test_report_all_rows_rejected`).
