# Reference Material

Put the original source material for the project here: proposals, manuscripts, client briefs, interview notes, meeting notes, research papers, screenshots, sample spreadsheets.

## Rules

- Never put passwords, keys or real personal data here. Anonymize interview and survey notes first.
- Every file gets one row in `docs/context.md` section 13 with a short summary.
- For a long file (for example a 40-page PDF), ask Claude to write a short summary next to it, named like `proposal-summary.md`. Agents read the summary; the original stays as the source of truth.
- Mark outdated files as "outdated" in section 13 instead of deleting them.
- If any file is confidential, keep it out of Git: add `docs/reference/` (or that file) to `.gitignore`.
