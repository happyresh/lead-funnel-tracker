# Options Analysis Template

> Use this to compare ways of solving a problem before deciding (for example "pages load slowly", "which hosting to use"). Copy to `docs/options-<topic>.md`. Once a choice is made, record it in `docs/context.md` section 11, and open a change record if it changes something approved.

**Status:** Open, On hold (since when, why) or Decided (which option, date).

## Problem
What is wrong or needed, with evidence (measurements, file paths, user reports).

## Why It Happens
The causes found, with file paths.

## Options, Cheapest First

| Option | What it does | Effort | Gain | Risk | Reversible? |
|---|---|---|---|---|---|
| 1. Do nothing | | none | none | | yes |
| 2. | | small, medium or large | | | |

## Constraints
Rules any option must respect (security, privacy, budget, deadline, no new dependencies).

## Recommendation
The option to choose and why, and what to measure to confirm it worked.
