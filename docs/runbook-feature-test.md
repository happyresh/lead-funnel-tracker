# Runbook: Manual Feature Test

> A step-by-step manual test script for one feature, for user acceptance testing, a tester or the developer before a demo. Copy to `docs/runbook-test-<feature>.md`. Automated tests remain the main proof; this covers what is easier to check by hand.

**Feature:** the PRD feature ID and name (for example F1 Sign in).
**Test rows covered:** the QAD row IDs.

## 1. Preconditions
- Environment (local, staging) and its URL.
- Accounts needed, by role.
- Data that must exist first.

## 2. Cheat Sheet
Values, codes or field names the tester needs, so they do not have to look them up.

## 6. Known Limits
What this script does not cover.

## 7. Result
Date, tester role, pass or fail, and links to any issues found.
