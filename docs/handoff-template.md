# Handoff Template

> Use a handoff when work stops mid-task and another person, another computer or a new Claude session must continue it (for example a long plan split over days). Copy to `docs/handoff-<short-name>.md` and delete it once the work is merged. For the everyday project position, use `docs/context.md` section 2 instead.

**Date:** write the date.
**Plan or change record:** the file this work belongs to.
**Branch / worktree:** the branch name and folder.

## Where Things Are
- Files changed so far and what each change does.
- Tests added and whether they pass.

## Task State

| Task | State | Notes |
|---|---|---|
| Task 1 | Done, In progress or Not started | |

## Decisions Carried Over
Rulings made during the work that the next person must respect.

## Constraints
Rules that still apply (do not edit migration X, keep API signature Y).

## Next Action
The exact next step, and the command to verify it.
